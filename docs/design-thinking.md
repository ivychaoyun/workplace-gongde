# Design Thinking｜職場功德所

## 同理：在想解法之前，先理解人

- **面向：** 我們（職場情緒與幸福感）
- **現象：** 工作中經常遇到需求不明、反覆改稿、臨時加工作或協助變主責等情況。當下雖然不滿，卻不方便直接向主管或同事表達；找人抱怨時，有時又得到「想開一點」的勸說，反而覺得自己的處境沒有被理解。
- **感受：** 煩躁、委屈、無奈與疲累，希望有人理解自己的不滿，能自在吐槽、笑一下，暫時從工作情緒中抽離。

## 定義：把觀察收斂成要解的問題

- **人物：** 怡安，32 歲，專案企劃，同時處理多項任務，經常面對臨時交辦與需求變動。平時會透過迷因或音樂調整心情，但不一定方便向身邊的人抱怨。
- **痛點：** 工作受挫時，缺少一個能安心抒發、不必顧慮職場人際關係，也不會立即被說教的情緒出口；她需要先被理解，再自行決定要休息或處理問題。
- **HMW：** 我們可以如何透過幽默與音樂，讓員工在職場煩躁時感到被理解，並獲得片刻喘息？

## 發想：提出可能的解法

- **方案名稱：** 職場功德所
- **核心概念：** 以「把怨氣寄放、把功德帶走」為敘事，結合腹黑嘴替、迷因梗圖、音樂與趣味迴向，提供短暫的情緒出口。
- **互動方式：** 輸入抱怨或選擇職場情境，再選擇「陪我吐槽／讓我靜靜／給我勇氣」，取得對應的回應與陪伴。
- **設計原則：** 先理解，不強迫正向思考；功德代表照顧自己，也包含休息、拒絕與確認界線。

## 原型：把想法做成可以體驗的東西

- **成品：** 可操作的網頁原型＋可下載或列印的「今日功德單」
- **體驗流程：** 寄放抱怨 → 選擇陪伴模式 → 查看嘴替與梗圖 → 聆聽音樂與觀看動畫 → 領取功德單
- **初版範圍：** 猜主管想法、反覆改稿、臨時加單、救火接手、休假被找等五類情境
- **內容示例：**
  - 嘴替：「需求不講，想法要猜。你找的是企劃，還是觀落陰？」
  - 判詞：「本案缺乏需求，暫列靈異事件。」
  - 迴向：「願所有需求，都能在第三次修改前現出原形。」

## 測試：確認體驗是否符合需求

- **方式：** 邀請有工作經驗者試用，觀察操作過程並蒐集回饋。
- **重點：** 文案是否符合情境、是否感到被理解、梗圖是否好笑或令人不舒服，以及是否獲得短暫喘息。
- **調整：** 依回饋修改嘴度、圖文搭配、音樂選項與操作流程。

> 註：人物設定與需求目前為初步假設，待訪談與試用確認；尚不宣稱具有提升幸福感的實證效果。
