# 分工表

## 體驗流程

**寄放抱怨 → 抱怨專輯（饒舌主打歌＋封面）→ 敲木魚 → 功德圓滿，分享到社群**

1. **寄放**：選情境或自由輸入，「今天受的氣，先寄放這裡。」
2. **抱怨專輯**：嘴替一句話、專輯封面（梗圖＋判詞當專輯名）、30 秒饒舌主打歌與歌詞。
3. **敲木魚**：敲滿 10 下，把怨氣敲散。
4. **功德圓滿**：勾選今天照顧自己的事，產生分享圖，可以下載或分享到 IG、LINE。

**原則**：全部在瀏覽器裡完成，使用者的抱怨不上傳。功德不等於忍耐。

---

四個分支、四個人。每個分支有自己「主要負責」的檔案，盡量只改自己的檔案，就不容易衝突。
做完一個段落就開 Pull Request 合併回 `main`，不用等全部做完。

| 分支 | 負責人 | 主要負責的檔案 |
| --- | --- | --- |
| `feature/memes-humor` 梗圖＋地獄梗文案 | （填名字） | `js/content.js`、`assets/memes/` |
| `feature/rap-mode` 饒舌主打歌 | （填名字） | `js/rap.js`、`css/rap.css`、`assets/music/album/` |
| `feature/album` 專輯封面與專輯頁 | （填名字） | `js/album.js`、`css/style.css` 的專輯區塊 |
| `feature/merit-share` 木魚、功德圓滿、社群分享 | （填名字） | `js/merit.js`、`css/style.css` 的木魚與功德圓滿區塊 |

`index.html`、`js/app.js` 和 `css/style.css` 是共用檔案，要改之前先在群組講一聲。

## feature/memes-humor｜梗圖＋地獄梗文案

圖跟文由同一個人負責，比較好搭配。

- [ ] 每個情境的 `roast`（嘴替）各寫 3～5 句候選，挑最好笑的
- [ ] 判詞 `verdict` 會當成專輯名：短、有梗、像宮廟公文
- [ ] 迴向 `blessing` 會印在分享圖上，一兩行內寫完
- [ ] 五個情境＋「其他」各做一張梗圖，依檔名放進 `assets/memes/`（`guess.png`、`revise.png`、`rush.png`、`firefight.png`、`leave.png`、`other.png`）
  - 要能當 1:1 封面，畫面中央留空間放專輯名
  - 寬度 1080px、單張 500KB 以內
- [ ] 新增情境（例如：會議開不完、功勞被搶、績效面談），記得一起補梗圖，並通知 rap-mode 補歌詞
- [ ] 只用自製或有授權的圖，來源記在 `assets/memes/CREDITS.md`
- 地獄梗的界線：酸情境、不酸人；不拿死亡、疾病、身心障礙、性別、族群開玩笑；**不把忍耐包裝成美德**

## feature/rap-mode｜饒舌主打歌

- [ ] 改寫 `RAP_VERSES` 裡每個情境的四句歌詞（現在是草稿），押韻、有節奏感
- [ ] 用 AI 音樂工具替每個情境做一首 30 秒的歌，放 `assets/music/album/<情境id>.mp3`
  - 選工具前先看授權條款，記下工具名稱、方案與生成日期，寫在 `assets/music/CREDITS.md`
  - 歌詞用 `RAP_VERSES` 的版本，讓網頁字幕和歌對得上
- [ ] `startRap()`：歌詞跟著音樂一行一行亮起來，像卡拉 OK 字幕
- [ ] 進階：用瀏覽器的語音朗讀（Web Speech API，選 zh-TW 聲音）把使用者輸入的關鍵字念在 beat 上，錄成自己的版本；不上傳任何內容
- 歌詞一樣遵守地獄梗的界線

## feature/album｜專輯封面與專輯頁

- [ ] 改進 `drawCover()`：字體、排版、加上專輯感的細節（曲目編號、條碼、「Parental Advisory」風格的小標）
- [ ] 沒有梗圖時的預設封面，讓每個情境有不同配色
- [ ] 專輯頁版面：封面、嘴替、主打歌、歌詞的排列，手機和電腦都要好看
- [ ] 進場動畫：例如黑膠唱片從封套滑出、封面翻轉亮相

## feature/merit-share｜木魚、功德圓滿、社群分享

- [ ] 木魚：敲擊音效、敲滿時的「功德圓滿」動畫（例如金光、煙霧）
- [ ] 調整 `FISH_GOAL`（現在敲 10 下），試用後決定幾下最剛好
- [ ] 分享圖 `drawShareCard()`：印章、迴向、今日功德的排版；另做 IG 限動尺寸（1080×1920）
- [ ] 分享：手機上用系統分享（已有基本版），電腦上改成下載圖片；測試 IG、LINE、Threads
- [ ] 試用時觀察：大家敢不敢分享？分享圖上會不會透露太多工作細節？
