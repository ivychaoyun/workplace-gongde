# 分工表

四個分支、四個人。每個分支有自己「主要負責」的檔案，盡量只改自己的檔案，就不容易衝突。
做完一個段落就開 Pull Request 合併回 `main`，不用等全部做完。

| 分支 | 負責人 | 主要負責的檔案 |
| --- | --- | --- |
| `feature/memes` 補梗圖 | （填名字） | `assets/memes/` |
| `feature/dark-humor` 地獄梗文案 | （填名字） | `js/content.js` |
| `feature/mode-experience` 陪伴模式體驗 | （填名字） | `js/modes.js`、`css/modes.css` |
| `feature/music-visual` 音樂與視覺 | （填名字） | `assets/music/`、`css/style.css` |

`index.html` 和 `js/app.js` 是共用檔案，要改之前先在群組講一聲。

---

## feature/memes｜補梗圖

- [ ] 五個情境＋「其他」各做一張梗圖，依檔名放進 `assets/memes/`（`guess.png`、`revise.png`、`rush.png`、`firefight.png`、`leave.png`、`other.png`）
- [ ] 圖片寬度建議 1080px 以內、單張 500KB 以內
- [ ] 只用自己做的、或有授權可以使用的圖，來源記在 `assets/memes/CREDITS.md`
- [ ] 想要一個情境多張隨機出現：跟 `feature/dark-humor` 討論在 `content.js` 加欄位

## feature/dark-humor｜地獄梗文案

- [ ] 每個情境的 `roast`（嘴替）各寫 3～5 句候選，挑最好笑的
- [ ] 判詞 `verdict`、迴向 `blessing` 統一成「宮廟公文」的語氣
- [ ] 新增情境（例如：會議開不完、功勞被搶、績效面談）
- [ ] 準備 10 句以上給試用者評分，記錄在 `docs/` 裡
- 地獄梗的界線：酸情境、不酸人；不拿死亡、疾病、身心障礙、性別、族群開玩笑；**不把忍耐包裝成美德**

## feature/mode-experience｜陪伴模式體驗

讓三種模式的體驗不只是文字不同。效果寫在 `js/modes.js`，樣式寫在 `css/modes.css`。

- [ ] 陪我吐槽：嘴替逐字打出、畫面震動、木魚敲得更用力
- [ ] 讓我靜靜：畫面變暗、呼吸引導動畫（吸 4 秒、停 4 秒、吐 4 秒）、木魚變慢
- [ ] 給我勇氣：顯示開口話術，加「複製這句話」按鈕
- [ ] 回應頁可以「再來一句」換一句嘴替（需要 `dark-humor` 提供多句）

## feature/music-visual｜音樂與視覺

- [ ] 三種模式各一首音樂：`assets/music/roast.mp3`、`quiet.mp3`、`courage.mp3`，用免版稅或自製音樂，來源記在 `assets/music/CREDITS.md`
- [ ] 首頁加一段「寄放怨氣」的動畫（例如：怨氣飄進香爐）
- [ ] 功德單設計升級：印章、紋樣、可直接分享到社群的圖片尺寸
- [ ] 檢查手機版排版與文字對比
