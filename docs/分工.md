# 分工表

依照[劇本](劇本.md)的段落分工，每個人一個分支，分支名稱就是自己的名字。

## 故事流程

**辦公室遇到鳥事 → 時間暫停、靈魂出竅唱饒舌 → 飄到廟裡變成小和尚 → 靜坐、心經、敲木魚、抽籤 → 迴向給心理支持計畫 → 回到公司重新開始**

**原則**：全程玩家自己操作，每段都能跳過；先理解不說教；功德不等於忍耐；酸的是情境不是人。抱怨可以交給 AI，但服務不記錄、不儲存。

## 協作規則

- **小步合併**：每個人每週至少開一次 Pull Request，一個 PR 只放一件事。
- **合併日**：每週固定一天，趙芸把大家的 PR 合進 `main`，全組一起把流程走一遍，約 15 分鐘。
- **`main` 隨時能跑**：只有趙芸按 Merge。開 PR 前先把最新的 `main` 合進自己的分支，確認沒壞。
- **交接點先講好**：每一段的結尾就是下一段的開頭（例如「靈魂落地」交給第三幕），交接的方式先在群組講好。
- **用佔位內容先接起來**：素材還沒到時用「待補」佔位，不用互相等。

### 段落之間的交接
